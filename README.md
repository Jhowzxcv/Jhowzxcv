### 🚀 Projetos em Destaque

**[Ristretto (TCC)](https://github.com/Jhowzxcv/Ristretto_TCC)** • Java / Spring Boot 3  
API RESTful projetada para auxiliar indivíduos com TDAH na gestão de rotinas e tarefas diárias, reduzindo sobrecarga cognitiva através da fragmentação de tarefas e lembretes estruturados.  
* **Decisões técnicas:** Autenticação stateless via **JWT**, isolamento rígido entre entidades e DTOs, validações determinísticas de regras de recorrência de calendário (**RFC 5545 / iCal4j**), fusos horários e documentação OpenAPI/Swagger.

**[Ficha Forge](https://github.com/Jhowzxcv/ficha-forge)** • Python  
Escreve a história de um personagem de RPG (Ordem Paranormal) e recebe a ficha pronta e calculada.  
* **Decisão de projeto:** **LLM não calcula**. O modelo interpreta a história e escolhe classe, origem e perícias; o motor em código calcula PV/PE/Sanidade e valida a build contra as regras — se vier ilegal, devolve os erros e pede correção em loops controlados. Roda como desktop, CLI e PWA sobre a mesma engine.

**[Sondagem Véspera](https://github.com/Jhowzxcv/sondagem-vespera)** • JavaScript / WebGL / Three.js  
Mapa orbital 3D interativo de um sistema estelar fictício com física de órbitas keplerianas, fotometria de trânsito planetário em tempo real e visualização espacial imersiva.

**[Formação Java & Spring Boot](https://github.com/Jhowzxcv/Alura_Java)** • Java / Spring Boot 3  
Repositório central reunindo 10 cursos da Formação Java da Alura: desde fundamentos de POO, Coleções e Consumo de APIs até arquitetura corporativa completa com Spring Data JPA, PostgreSQL, Spring Security com JWT e a **Voll.med API**.

### 🧠 Como trabalho

- **Modelo o domínio antes** de sair criando endpoint.
- **Separo DTO de entidade** — o contrato da API não é o banco.
- **Coloco a validação em código determinístico**, não na camada que pode alucinar.
- **Prefiro corrigir a causa da query lenta** a botar cache em cima dela.
